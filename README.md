# meta-notation
A notation for largest possible set of languages. It should focus on parsing ( ), { }, [ ], ' ', \` \`, " " and so on.

It should be simplier version of links-notation.

So it should support plain sequences of references and also nested, but without ability to use or parse `:` as way to define a link's self reference.

That way it will be compatible with much larger set of languages.

It can be similar to my old idea https://github.com/konard/metalanguage.

But we can now have all tools in https://github.com/link-foundation/links-notation to do it right and efficient.
